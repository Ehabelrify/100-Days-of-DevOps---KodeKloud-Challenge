## About This Challenge

The 100 Days of DevOps is a structured learning program covering:

- **Linux Administration** (Days 1-20) — User management, permissions, system configuration
- **Git & Version Control** (Days 21-34) — Branching, merging, workflows
- **Docker & Containerization** (Days 35-47) — Images, containers, networking
- **Kubernetes** (Days 48-67) — Pod deployment, scaling, storage
- **Jenkins & CI/CD** (Days 68-81) — Pipeline automation, job configuration
- **Ansible** (Days 82-93) — Configuration management, automation
- **Terraform & AWS** (Days 94-100) — Infrastructure as code, cloud provisioning
